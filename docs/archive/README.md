# Archive

Documents from before the project pivoted to Replayable.

The team's earlier SE390/SE490 work was a crowdsourced climbing-route catalogue.
Those documents are kept here rather than deleted — they are a real record of
the team's process, and the pivot itself is part of the project's history — but
they describe software that does not exist in this repository.

| File | What it describes |
|---|---|
| `pre-pivot-climbing-app-design.md` | FastAPI + SQLModel backend for a climbing-gym route catalogue, with Gemini-based duplicate matching. Unrelated to Replayable. |

Nothing in this directory is current. For Replayable's design see
[`docs/design/README.md`](../design/README.md) and
[`docs/limitations.md`](../limitations.md).
